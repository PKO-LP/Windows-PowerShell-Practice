# Дополнительная практика 2. Найдите потерянную памятку


[К оглавлению](README.md)

## Найдите рабочий стол через CMD

1. Откройте «Командную строку» через меню «Пуск».
2. Посмотрите на путь перед знаком `>`. Он показывает текущую папку.
3. Если вы уже на рабочем столе, сначала поднимитесь на уровень выше с помощью `cd ..`. Если вы в другой подпапке своего профиля, поднимайтесь по одному уровню с помощью `cd ..` и после каждого перехода просматривайте список командой `dir`.
4. Найдите папку рабочего стола в списке и перейдите в неё с помощью `cd`, подставив имя из списка. Она может называться `Desktop` и находиться внутри OneDrive. Если не можете её найти, уточните расположение в Проводнике, затем выполните переходы в CMD.
5. Сверьте путь в приглашении CMD с расположением рабочего стола. Все действия ниже выполняйте в своей новой учебной папке. Если предложенное имя уже занято, добавьте к нему свои инициалы.

## Выполните задание

При переносе документов памятка дежурного попала в папку со старыми материалами. Найдите её по спискам файлов, верните в папку смены и запишите, где она была.

1. Создайте на рабочем столе папку `CMD-Search` с помощью `mkdir` и зайдите в неё командой `cd`. Создайте три подпапки: `Shift`, `Archive` и `Data_Folder`.
2. Подготовьте исходную ситуацию с помощью `echo` и знака `>`. Запишите строку `Check the door before leaving` в файл `memo.txt` внутри `Archive`. В папке `Shift` создайте `schedule.txt` со строкой `Evening shift`. Вернитесь в `CMD-Search`, если заходили в подпапки. Для подъёма используйте `cd ..`.
3. С помощью `dir` проверьте обе папки. Запишите в тетрадь, где найден `memo.txt` и какого файла в папке смены пока нет.
4. Переместите только `memo.txt` из архива в папку смены с помощью `move`. Командой `dir` проверьте обе папки. Расписание должно остаться на месте.
5. Создайте в основной папке файл `report.txt` с помощью `echo` и `>`. В одной строке запишите, где нашли памятку и куда перенесли. Знак `>` записывает вывод в указанный файл.
6. Из `CMD-Search` проверьте через `dir`, что учебная `Data_Folder` пуста. Удалите её командой `rmdir` с ключом `/s`. Сверьте имя папки перед подтверждением.

## Что показать в конце

Покажите через `dir` две папки. В `Shift` лежат `memo.txt` и `schedule.txt`, а `Archive` пуста. В основной папке остался `report.txt`, а `Data_Folder` исчезла.
