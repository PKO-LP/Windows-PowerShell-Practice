# Практика 1. Три модуля на связи

Вы собираете учебный проект. В первом каталоге лежит пробный модуль, во втором — два варианта приветствия, а в третьем — карточка проекта и её резервная копия.

## Подготовка

Откройте **Проводник → Рабочий стол**. Щёлкните по адресной строке, введите `cmd` и нажмите **Enter**. CMD откроется на рабочем столе. Выполняйте команды по одной.

Чтобы создать и заполнить файл, введите в CMD `notepad имя_файла`. Подтвердите создание, внесите текст, сохраните его через **Ctrl + S** и закройте Блокнот.

## Создайте структуру

1. Командой `mkdir` создайте папку `D1` и перейдите в неё через `cd D1`.
2. Создайте внутри три папки одной командой `mkdir A1 B1 C1`. Проверьте их командой `dir /b`.

## A1. Проверьте первое приветствие

1. Перейдите в `A1`. Создайте файл `a1_module.py` с таким кодом:

   ```python
   print("Hello from A")
   ```

2. Создайте `README.md` со строкой `A documentation`. Проверьте её командой `type README.md`.
3. Выполните `cd ..`, чтобы вернуться в `D1`.

## B1. Соберите два варианта

1. Перейдите в `B1`. Создайте `b1_module.py` с кодом `print("Hello from B")`.
2. Создайте `b2_module.py` с кодом `print("Hello from B2")`.
3. Создайте `README.md` со строкой `B_1 B_2 documentation`.
4. Выполните `dir /b *.py`. В списке должно быть два файла. Вернитесь в `D1` через `cd ..`.

## C1. Подготовьте карточку проекта

1. Перейдите в `C1`. Создайте `draft.py`. Пусть программа выводит название проекта и имя автора на отдельных строках. Замените пример своими данными:

   ```python
   print("Project: CMD Explorer")
   print("Author: Alex")
   ```

2. Командой `ren` переименуйте `draft.py` в `c1_module.py`.
3. Создайте папку `backup` внутри `C1` и командой `copy` поместите туда копию `c1_module.py`.
4. В `C1` создайте `README.md`. Напишите, что выводит программа и где лежит её копия.

## Покажите результат

Из `D1` выполните `tree /f /a`. Покажите преподавателю три папки, четыре исходных Python-файла, три файла `README.md` и копию `c1_module.py` в `C1\backup`. Если установлен Python, из `C1` запустите `py c1_module.py` и покажите карточку проекта.
