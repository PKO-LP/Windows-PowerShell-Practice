# Практика 2. Пропавший экспонат

Перед открытием выставки пропала карточка метеорита. В журнале есть инвентарный номер. Найдите нужный файл по его содержимому и верните карточку в зал.

## Подготовка

Откройте **Проводник → Рабочий стол**. Щёлкните по адресной строке, введите `cmd` и нажмите **Enter**. CMD откроется на рабочем столе. Выполняйте команды по одной.

Чтобы создать и заполнить файл, введите в CMD `notepad имя_файла`. Подтвердите создание, внесите текст, сохраните его через **Ctrl + S** и закройте Блокнот.

## Журнал дежурного

1. Создайте на рабочем столе папку `D2` и перейдите в неё. Создайте три подпапки `Journal`, `Storage` и `Exhibit`.
2. В `Journal` создайте файл `incident.txt` со строкой `Missing exhibit: M-17`. Командой `type` прочитайте запись и выпишите инвентарный номер.
3. Вернитесь в `D2` через `cd ..`.

## Хранилище

1. Перейдите в `Storage`. Создайте три карточки: `box_a.txt` со строкой `M-12 Quartz`, `box_b.txt` со строкой `M-17 Meteorite` и `box_c.txt` со строкой `M-23 Amber`.
2. Найдите карточку по номеру командой `findstr /m /c:"M-17" *.txt`. Ключ `/m` выводит имя файла с совпадением. Запишите имя найденного файла.
3. Командой `move` перенесите найденный файл в соседнюю папку `..\Exhibit`. Проверьте через `dir /b *.txt`, какие две карточки остались в хранилище.

## Выставочный зал

1. Через `D2` перейдите в `Exhibit`. Командой `ren` присвойте найденной карточке имя `meteorite.txt`.
2. Создайте файл `return-report.txt`. Укажите номер экспоната, исходное имя карточки и её новое имя.
3. Командой `type meteorite.txt` подтвердите, что в зал вернули карточку метеорита.

## Покажите результат

Покажите строку с номером экспоната, две оставшиеся карточки в `Storage` и итоговые файлы в `Exhibit`.
