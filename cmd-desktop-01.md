# Дополнительная практика 1. Оснащение аудитории

[К оглавлению](README.md)

## Как дойти до рабочего стола

1. Нажмите **Пуск**, наберите **cmd** и откройте **Командную строку**.
2. Посмотрите на путь слева от знака `>`. Это ваша текущая папка. Например, `C:\Users\Student\Documents>` означает, что вы в «Документах» пользователя Student. В команды из задания этот путь копировать не нужно.
### Поднимитесь на уровень выше

Если вы в подпапке своего профиля, поднимитесь на один уровень.

```cmd
cd ..
```

Две точки означают папку на уровень выше. Например, из `C:\Users\Student\Documents` вы попадёте в `C:\Users\Student`. Если путь уже заканчивается именем вашего профиля, переходите к просмотру списка. Если вы уже на рабочем столе, переходите к заданию.

### Посмотрите список папок

Посмотрите, какие папки есть на этом уровне.

```cmd
dir
```

В списке ищите строки с пометкой `<DIR>`. Если `Desktop` ещё не видно и вы находитесь внутри своего профиля, повторите подъём и просмотр. Если после подъёма вы оказались в `C:\Users`, командой `cd` вернитесь в папку своего профиля, взяв её имя из списка.

### Откройте рабочий стол

Если `dir` показала папку `Desktop`, откройте её.

```cmd
cd Desktop
```

`Desktop` — имя папки из списка. Если имя содержит пробелы, заключите его в двойные кавычки. Проверьте, что приглашение CMD теперь заканчивается именем папки рабочего стола. Можно снова ввести `dir` и сверить знакомые файлы с Проводником.

**Если рабочего стола нет в списке или видите две папки Desktop.** Откройте рабочий стол в Проводнике, щёлкните по адресной строке и посмотрите физический путь. Он может выглядеть как `C:\Users\Student\OneDrive\Desktop`. Из папки своего профиля сначала перейдите командой `cd OneDrive`, затем введите `dir` и откройте нужную папку через `cd Desktop`. Используйте названия именно со своего компьютера. Если текущая папка находится на другом диске или вне профиля, сначала перейдите в папку своего профиля командой `cd /d "%USERPROFILE%"`, затем продолжите поиск через `dir` и `cd`. Если адресная строка показывает только «Рабочий стол», попробуйте открыть свойства этой папки в Проводнике и посмотреть вкладку «Расположение».

## Порядок работы

Копируйте по одной строке. После вставки нажимайте **Enter** и сверяйте результат под командой. Начинайте работу внутри найденного рабочего стола. Если одноимённая учебная папка уже существует, выберите новое имя для неё и используйте его в обеих первых командах.

Подготовьте список оборудования для техника. Создайте рабочий список во временной папке, затем вынесите его в основную папку под понятным именем.

### Действие 1

```cmd
mkdir CMD-Room
```

Создайте учебную папку `CMD-Room` на рабочем столе. При успехе CMD обычно просто показывает новое приглашение.

### Действие 2

```cmd
cd CMD-Room
```

Откройте учебную папку. Путь перед `>` должен заканчиваться на `\CMD-Room`.

### Действие 3

```cmd
mkdir Data_Folder
```

Создайте временную подпапку `Data_Folder`. Имя понадобится в следующих командах.

### Действие 4

```cmd
cd Data_Folder
```

Откройте временную папку. В приглашении видно `Data_Folder>`.

### Действие 5

```cmd
echo Check projector and cables>draft.txt
```

Запишите строку в черновик. Знак `>` направляет вывод в файл. Можно заменить фразу слева от знака.

### Действие 6

```cmd
dir
```

Убедитесь, что появился `draft.txt`.

### Действие 7

```cmd
move draft.txt ..\equipment.txt
```

Перенесите файл на уровень выше и дайте ему новое имя. `..\` указывает на родительскую папку.

### Действие 8

```cmd
cd ..
```

Вернитесь в `CMD-Room`.

### Действие 9

```cmd
dir
```

Убедитесь, что рядом с `Data_Folder` появился `equipment.txt`.

### Действие 10

```cmd
dir Data_Folder
```

Проверьте содержимое временной папки перед удалением. Если там есть чужие файлы, остановитесь.

### Действие 11

```cmd
rmdir Data_Folder /s
```

Введите команду только из своей папки `CMD-Room`. Ключ `/s` удаляет указанную папку вместе с её содержимым. При запросе `(Y/N)` введите `Y` и нажмите **Enter**. Если запрос на другом языке, используйте показанную в нём букву для «да».

### Действие 12

```cmd
dir
```

Проверьте, что строки `Data_Folder` больше нет и итоговый файл или папка на месте.

## Что показать в конце

Откройте учебную папку `CMD-Room` на рабочем столе в Проводнике. В ней должны быть следующие файлы.

- `equipment.txt`

Покажите вывод последней команды `dir`, где временной папки `Data_Folder` уже нет. Если итоговые файлы лежат в подпапке, откройте её и покажите оба файла.
