# Дополнительная практика 1. Оснащение аудитории

[К оглавлению](README.md)

## Найдите рабочий стол через CMD

1. Откройте «Командную строку» через меню «Пуск».
2. Посмотрите на путь перед знаком `>`. Он показывает текущую папку.
3. Если вы уже на рабочем столе, сначала поднимитесь на уровень выше. Если вы в другой подпапке своего профиля, поднимайтесь по одному уровню и просматривайте список папок после каждого перехода.
4. Найдите папку рабочего стола в списке и перейдите в неё по имени. Она может называться `Desktop` и находиться внутри OneDrive. Если не можете её найти, уточните расположение в Проводнике, затем выполните переходы в CMD.
5. Сверьте путь в приглашении CMD с расположением рабочего стола. Все действия ниже выполняйте в своей новой учебной папке. Если предложенное имя уже занято, добавьте к нему свои инициалы.

## Выполните задание

Подготовьте список оборудования для техника. Выполняйте действия в CMD. Для записи текста используйте перенаправление вывода в файл.

1. Создайте на рабочем столе папку `CMD-Room`, зайдите в неё и создайте подпапку `Data_Folder`.
2. Зайдите в `Data_Folder`. Создайте файл `draft.txt` с одной строкой про оборудование, которое нужно проверить. Просмотрите содержимое папки.
3. Одним действием перенесите черновик на уровень выше и дайте ему имя `equipment.txt`.
4. Вернитесь в учебную папку и убедитесь, что итоговый файл находится рядом с `Data_Folder`.
5. Из основной учебной папки просмотрите содержимое `Data_Folder`. Если там есть чужие файлы, остановитесь.
6. Удалите только `Data_Folder` вместе с её содержимым. Перед подтверждением сверьте имя папки и путь. Проверьте, что временная папка исчезла, а итоговые файлы сохранились.

## Что показать в конце

В учебной папке должен остаться только файл `equipment.txt` с вашей строкой.

Покажите путь к учебной папке на рабочем столе и итоговые файлы в списке CMD.
