# Дополнительная практика 1. Оснащение аудитории

[К оглавлению](README.md)

## Найдите рабочий стол через CMD

1. Откройте «Командную строку» через меню «Пуск».
2. Посмотрите на путь перед знаком `>`. Он показывает текущую папку.
3. Если вы уже на рабочем столе, сначала поднимитесь на уровень выше с помощью `cd ..`. Если вы в другой подпапке своего профиля, поднимайтесь по одному уровню с помощью `cd ..` и после каждого перехода просматривайте список командой `dir`.
4. Найдите папку рабочего стола в списке и перейдите в неё с помощью `cd`, подставив имя из списка. Она может называться `Desktop` и находиться внутри OneDrive. Если не можете её найти, уточните расположение в Проводнике, затем выполните переходы в CMD.
5. Сверьте путь в приглашении CMD с расположением рабочего стола. Все действия ниже выполняйте в своей новой учебной папке. Если предложенное имя уже занято, добавьте к нему свои инициалы.

## Выполните задание

Подготовьте список оборудования для техника. Выполняйте действия в CMD. Для записи строки используйте `echo`. Знак `>` направляет вывод в указанный файл и заменяет его содержимое, если он уже существует.

1. С помощью `mkdir` создайте на рабочем столе папку `CMD-Room`. Перейдите в неё командой `cd` и с помощью `mkdir` создайте подпапку `Data_Folder`.
2. Зайдите в `Data_Folder` с помощью `cd`. Используйте `echo` и `>`, чтобы создать файл `draft.txt` с одной строкой про оборудование, которое нужно проверить. Просмотрите содержимое папки командой `dir`.
3. С помощью `move` одним действием перенесите черновик на уровень выше и дайте ему имя `equipment.txt`.
4. Вернитесь в учебную папку через `cd ..` и с помощью `dir` убедитесь, что итоговый файл находится рядом с `Data_Folder`.
5. Из основной учебной папки с помощью `dir` просмотрите содержимое `Data_Folder`. Если там есть чужие файлы, остановитесь.
6. Удалите только `Data_Folder` командой `rmdir` с ключом `/s`. Этот ключ позволяет удалить папку вместе с её содержимым. Перед подтверждением сверьте имя папки и путь. Введите `dir` и проверьте, что временная папка исчезла, а итоговые файлы сохранились.

## Что показать в конце

В учебной папке должен остаться только файл `equipment.txt` с вашей строкой.

Покажите путь к учебной папке на рабочем столе и итоговые файлы в списке CMD.
