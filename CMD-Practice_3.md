# Практика 3. Восстановите бортовой журнал

После сбоя на учебной станции журнал наблюдений обрывается на середине. Соберите его из трёх фрагментов, сравните с эталоном и подготовьте пакет для передачи.

## Подготовка

Откройте **Проводник → Рабочий стол**. Щёлкните по адресной строке, введите `cmd` и нажмите **Enter**. CMD откроется на рабочем столе. Выполняйте команды по одной.

Чтобы создать и заполнить файл, введите в CMD `notepad имя_файла`. Подтвердите создание, внесите текст, сохраните его через **Ctrl + S** и закройте Блокнот.

## Фрагменты журнала

1. Создайте на рабочем столе папку `D3` и перейдите в неё. Создайте подпапки `Fragments`, `Check` и `Delivery`.
2. Из `D3` выполните три команды. Каждая запишет одну строку в отдельный файл.

   ```cmd
   echo 08:00 Station online>Fragments\01.txt
   echo 08:15 Sensor checked>Fragments\02.txt
   echo 08:30 Data received>Fragments\03.txt
   ```

3. Перейдите в `Fragments` и проверьте командой `dir /b`, что все три файла на месте.

## Сборка и проверка

1. Оставаясь в `Fragments`, выполните команды. Знак `>` создаёт файл со стартовой записью, а `>>` дописывает строки в конец.

   ```cmd
   type 01.txt > ..\Check\station.log
   type 02.txt >> ..\Check\station.log
   type 03.txt >> ..\Check\station.log
   ```

2. Через `D3` перейдите в `Check`. В Блокноте создайте `expected.log` с тремя строками из образца. Нажмите **Enter** после последней строки и сохраните файл в кодировке UTF-8.

   ```text
   08:00 Station online
   08:15 Sensor checked
   08:30 Data received
   ```

3. Сравните файлы командой `fc /l station.log expected.log`. Если команда покажет различия, найдите ошибку во фрагментах или в эталоне, исправьте её и повторите проверку.

## Пакет для передачи

1. Из `Check` скопируйте проверенный `station.log` в `..\Delivery` командой `copy`.
2. Через `D3` перейдите в `Delivery`. Создайте `README.md` и запишите, сколько записей в журнале и в какое время станция получила данные.
3. Выполните `dir /b` и `type station.log`. Покажите два итоговых файла и три записи в хронологическом порядке.

**Дополнительный вызов.** В `Check` временно поменяйте местами две строки в `expected.log`. Снова выполните `fc /l`, покажите, как команда отмечает расхождение, и восстановите эталон.
