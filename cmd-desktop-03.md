# Дополнительная практика 3. Разбор учебной заявки

[К оглавлению](README.md)

## Найдите рабочий стол через CMD

1. Откройте «Командную строку» через меню «Пуск».
2. Посмотрите на путь перед знаком `>`. Он показывает текущую папку.
3. Если вы уже на рабочем столе, сначала поднимитесь на уровень выше с помощью `cd ..`. Если вы в другой подпапке своего профиля, поднимайтесь по одному уровню с помощью `cd ..` и после каждого перехода просматривайте список командой `dir`.
4. Найдите папку рабочего стола в списке и перейдите в неё с помощью `cd`, подставив имя из списка. Она может называться `Desktop` и находиться внутри OneDrive. Если не можете её найти, уточните расположение в Проводнике, затем выполните переходы в CMD.
5. Сверьте путь в приглашении CMD с расположением рабочего стола. Все действия ниже выполняйте в своей новой учебной папке. Если предложенное имя уже занято, добавьте к нему свои инициалы.

## Выполните задание

Обработайте заявку о неисправном принтере. Выполняйте действия в CMD. Для записи строки используйте `echo`. Знак `>` направляет вывод в указанный файл и заменяет его содержимое, если он уже существует.

1. С помощью `mkdir` создайте на рабочем столе папку `CMD-Ticket` и зайдите в неё командой `cd`. Командой `mkdir` создайте подпапки `Data_Folder` для очереди и `Archive` для архива.
2. В основной учебной папке с помощью `echo` и `>` создайте `request.txt` и запишите в него описание неисправности одной строкой.
3. Перенесите заявку в очередь с помощью `move`. Зайдите в `Data_Folder` командой `cd` и проверьте через `dir`, что файл появился.
4. Прямо из папки очереди с помощью `move` перенесите заявку в соседнюю папку архива. Вернитесь на уровень выше через `cd ..`.
5. С помощью `echo` и `>` создайте внутри `Archive` файл `response.txt` с одной строкой о том, что сделали с принтером. Проверьте содержимое архива командой `dir`.
6. Из основной учебной папки с помощью `dir` просмотрите содержимое `Data_Folder`. Если там есть чужие файлы, остановитесь.
7. Удалите только `Data_Folder` командой `rmdir` с ключом `/s`. Этот ключ позволяет удалить папку вместе с её содержимым. Перед подтверждением сверьте имя папки и путь. Введите `dir` и проверьте, что временная папка исчезла, а итоговые файлы сохранились.

## Что показать в конце

В учебной папке должна остаться только подпапка `Archive` с файлами `request.txt` и `response.txt`.

Покажите путь к учебной папке на рабочем столе и итоговые файлы в списке CMD.
