# Дополнительная практика 3. Разбор учебной заявки

[К оглавлению](README.md)

## Найдите рабочий стол через CMD

1. Откройте «Командную строку» через меню «Пуск».
2. Посмотрите на путь перед знаком `>`. Он показывает текущую папку.
3. Если вы уже на рабочем столе, сначала поднимитесь на уровень выше. Если вы в другой подпапке своего профиля, поднимайтесь по одному уровню и просматривайте список папок после каждого перехода.
4. Найдите папку рабочего стола в списке и перейдите в неё по имени. Она может называться `Desktop` и находиться внутри OneDrive. Если не можете её найти, уточните расположение в Проводнике, затем выполните переходы в CMD.
5. Сверьте путь в приглашении CMD с расположением рабочего стола. Все действия ниже выполняйте в своей новой учебной папке. Если предложенное имя уже занято, добавьте к нему свои инициалы.

## Выполните задание

Обработайте заявку о неисправном принтере. Выполняйте действия в CMD. Для записи текста используйте перенаправление вывода в файл.

1. Создайте на рабочем столе папку `CMD-Ticket` и зайдите в неё. Создайте подпапки `Data_Folder` для очереди и `Archive` для архива.
2. В основной учебной папке создайте `request.txt` и запишите в него описание неисправности одной строкой.
3. Перенесите заявку в очередь. Зайдите в `Data_Folder` и проверьте, что файл появился.
4. Прямо из папки очереди перенесите заявку в соседнюю папку архива. Вернитесь на уровень выше.
5. Создайте внутри `Archive` файл `response.txt` с одной строкой о том, что сделали с принтером. Проверьте содержимое архива.
6. Из основной учебной папки просмотрите содержимое `Data_Folder`. Если там есть чужие файлы, остановитесь.
7. Удалите только `Data_Folder` вместе с её содержимым. Перед подтверждением сверьте имя папки и путь. Проверьте, что временная папка исчезла, а итоговые файлы сохранились.

## Что показать в конце

В учебной папке должна остаться только подпапка `Archive` с файлами `request.txt` и `response.txt`.

Покажите путь к учебной папке на рабочем столе и итоговые файлы в списке CMD.
