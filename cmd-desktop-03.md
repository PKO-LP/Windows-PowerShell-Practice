# Дополнительная практика 3. Испытайте удаление папки с вложениями


[К оглавлению](README.md)

## Найдите рабочий стол через CMD

1. Откройте «Командную строку» через меню «Пуск».
2. Посмотрите на путь перед знаком `>`. Он показывает текущую папку.
3. Если вы уже на рабочем столе, сначала поднимитесь на уровень выше с помощью `cd ..`. Если вы в другой подпапке своего профиля, поднимайтесь по одному уровню с помощью `cd ..` и после каждого перехода просматривайте список командой `dir`.
4. Найдите папку рабочего стола в списке и перейдите в неё с помощью `cd`, подставив имя из списка. Она может называться `Desktop` и находиться внутри OneDrive. Если не можете её найти, уточните расположение в Проводнике, затем выполните переходы в CMD.
5. Сверьте путь в приглашении CMD с расположением рабочего стола. Все действия ниже выполняйте в своей новой учебной папке. Если предложенное имя уже занято, добавьте к нему свои инициалы.

## Выполните задание

Проверьте, почему перед удалением папки с вложениями нужно вынести нужные файлы. Сравните удаление непустой папки с ключом `/s` и без него на учебных данных.

1. Создайте на рабочем столе папку `CMD-Cleanup` с помощью `mkdir` и зайдите в неё командой `cd`. Внутри создайте `Data_Folder`. Зайдите в неё и создайте подпапку `Drafts`.
2. С помощью `echo` и знака `>` создайте в `Data_Folder` файл `keep.txt` со строкой `Keep this instruction`. Внутри `Drafts` создайте `test.txt` с произвольной строкой. Знак `>` записывает вывод в указанный файл.
3. С помощью `move` вынесите `keep.txt` на уровень выше, в `CMD-Cleanup`. Вернитесь туда через `cd ..` и проверьте с помощью `dir`, что `keep.txt` рядом с `Data_Folder`.
4. Проверьте через `dir`, что внутри `Data_Folder` осталась подпапка `Drafts` с вашим пробным файлом. Из `CMD-Cleanup` попробуйте удалить `Data_Folder` командой `rmdir` без ключа. Запишите сообщение CMD и проверьте через `dir`, что папка осталась. Сообщение об ошибке на этом шаге ожидаемо.
5. Из той же папки удалите `Data_Folder` командой `rmdir` с ключом `/s`. Этот ключ удаляет и вложенные папки. Перед подтверждением сверьте путь и имя удаляемой папки.
6. Введите `dir` и сравните результат с шагом 4. Запишите в тетради, почему первая попытка не удалась и что произошло после добавления ключа.

## Что показать в конце

Покажите итоговый список в CMD. В `CMD-Cleanup` остался только `keep.txt`. Покажите запись с результатами двух попыток удаления.
