# Старт — три практики в CMD

Откройте [оглавление](README.md) и нажмите ссылку на нужную пару в разделе командной строки Windows.

На каждой паре выполняйте основные блоки 1–15 по порядку. Если закончили раньше, продолжайте с блока 16. Одна команда — одна вставка в окно **«Командная строка»** и одно нажатие **Enter**. После каждой команды сверяйте результат с пояснением. В конце файла написано, что сдавать.
