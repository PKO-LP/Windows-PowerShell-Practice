# Старт — три самостоятельные работы

Откройте [README.md](README.md). Там находятся все команды, подсказки и ожидаемые результаты.

- **Пара 1** — папки, текстовые файлы, Блокнот и копирование.
- **Пара 2** — перенос копии из «Документов» на рабочий стол.
- **Пара 3** — сборка комплекта файлов по учебной заявке службы поддержки.

На каждой паре сначала откройте **Пуск → Windows PowerShell**. Затем выполните свой раздел README по порядку. Вставляйте по одной команде и нажимайте Enter. Для сдачи сделайте снимки результатов, указанных в конце раздела. Если закончили основной блок, выполните самостоятельную часть и дополнительное задание.

Если команда выдаёт ошибку, начните с подсказки под ней. Если ошибка остаётся, покажите преподавателю команду и первую строку ошибки.
