# Старт — три самостоятельные работы

Откройте [оглавление с тремя парами](README.md) и выберите номер своей пары. Сразу перейдите к **«Шагу 0»** в выбранном файле: там показано, как открыть Windows PowerShell и куда вставить первую строку.

Выполняйте шаги по порядку. Для сдачи ориентируйтесь на раздел **«Самостоятельная часть и сдача»** в конце своей пары. Если команда выдаёт ошибку, сначала прочитайте подсказку под ней.
